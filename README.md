NEXORA — Responsive Landing Page

A modern and responsive AI-themed landing page developed as part of the SkillCraft Technology Web Development Internship — Task 1.


🚀 Project Overview

NEXORA is a modern AI decision-intelligence themed landing page designed to demonstrate responsive web design and interactive navigation.

The website features a fixed navigation menu that dynamically changes its appearance when the user scrolls and provides interactive hover effects on navigation items.

## Task Requirement

Create an interactive navigation menu that changes color or style when scrolled or when hovering over a menu item. The navigation menu should have a fixed position and remain visible while scrolling.

## Requirement Implementation

| Requirement | Implementation |
|---|---|
| Fixed Navigation | Navigation bar remains fixed at the top |
| Hover Effect | Menu items change color and show an animated underline |
| Scroll Effect | Navbar changes style when the page is scrolled |
| Responsive Design | Mobile navigation menu with hamburger button |
| Smooth Navigation | Navigation links smoothly scroll to sections |

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using Live Server or open it directly in a browser.
